# 📷 Куда вставлять фото

Подробная карта всех мест в проекте, где используются изображения. Все пути — относительно корня сайта (`web/`).

---

## 🚗 Фото автомобилей

| Где используется | Откуда берётся | Как загрузить |
|---|---|---|
| Карточка авто в каталоге | `web/uploads/cars/<filename>` | **Через админку**: `/admin/car/update/<id>` → блок «Загрузить фото» |
| Главная страница (доступные авто) | `web/uploads/cars/<filename>` | То же |
| Карточка авто на странице бронирования | `web/uploads/cars/<filename>` | То же |
| Заглушка при отсутствии фото | `web/img/car-placeholder.svg` | Замените, если хотите свой плейсхолдер |

> **Размер:** рекомендуется 1200×800 px, JPG, до 1 МБ.
> **Главное фото** автомобиля выбирается автоматически (первое загруженное) или ставится флагом `is_main`.

## 👤 Аватары пользователей

| Где | Путь | Как |
|---|---|---|
| Header (avatar dropdown) | `web/uploads/avatars/<user_id>.jpg` | Если файла нет — отображаются инициалы пользователя на фирменном градиенте (это окей, можно ничего не делать) |

> Загрузка через профиль пока не реализована — можно добавить как функционал. Сейчас инициалов достаточно.

## 🏢 О компании (`/site/about`)

| Что заменить | Путь | Размер | Использование в шаблоне |
|---|---|---|---|
| **Hero-фото** | `web/img/about/hero.jpg` *(или .png/.svg)* | 1200×800 | Большое фото на главном баннере страницы «О компании» |
| **Фото команды** (4 человека) | `web/img/team/ceo.jpg`, `cto.jpg`, `coo.jpg`, `support.jpg` | 480×480 (квадратные) | Карточки команды |
| Заглушка команды | `web/img/team/placeholder.svg` | — | Показывается, если фото нет |

> Имена в `views/site/about.php` → массив `$team`. Если хотите больше/меньше людей — отредактируйте массив.

## 📞 Контакты (`/site/contacts`)

Карта рендерится через **Yandex Maps**, фото офиса не нужно. Координаты офиса в `views/site/contacts.php`:

```php
$officeLat = 55.7558;
$officeLng = 37.6173;
$officeAddress = 'Москва, ул. Тверская, 1';
```

Поменяйте на свои.

> Если хотите фото офиса как фон шапки — добавьте `web/img/office/hq.jpg` и расширьте шаблон.

## 🤝 Партнёры на главной (логотипы)

| Что заменить | Путь | Размер |
|---|---|---|
| Сбербанк | `web/img/partners/sberbank.svg` *(или .png)* | 200×80, прозрачный фон |
| Альфа-Банк | `web/img/partners/alfa.svg` | то же |
| ЮKassa | `web/img/partners/yookassa.svg` | то же |
| Яндекс | `web/img/partners/yandex.svg` | то же |
| ВТБ | `web/img/partners/vtb.svg` | то же |
| ОСАГО | `web/img/partners/osago.svg` | то же |
| Заглушка | `web/img/partners/placeholder.svg` | используется автоматически, если файла нет |

## 🏆 Награды (опционально)

В коде сейчас не используется, но папка готова: `web/img/awards/`. Можно добавить блок «Награды» на главную или в «О компании»:

```php
<img src="<?= Yii::getAlias('@web/img/awards/winner-2024.png') ?>">
```

## 💬 Аватары в отзывах на главной

Сейчас отзывы используют **иконки** (`fa-male`, `fa-female`) как плейсхолдеры. Чтобы поставить реальные фото:

В `views/site/index.php` найдите массив `$defaultReviews` и измените на:
```php
$defaultReviews = [
    ['Анна К.', 'Менеджер', 5, 'текст отзыва...', 'clients/anna.jpg'],
    // ...
];
```

И в шаблоне замените `<i class="fa-solid <?= $iconClass ?>"></i>` на:
```php
<img src="<?= Yii::getAlias('@web/img/' . $iconClass) ?>"
     style="width:100%;height:100%;object-fit:cover;border-radius:50%;"
     onerror="this.src='<?= Yii::getAlias('@web/img/clients/placeholder.svg') ?>';">
```

Файлы — в `web/img/clients/`, размер 80×80, обрезанные кружком.

## 🎨 Фавикон и логотип

| Что | Путь | Использование |
|---|---|---|
| Favicon (вкладка браузера) | `web/img/logo.svg` | Уже подключён в layout |
| Логотип в шапке | SVG inline через FontAwesome `fa-road` на градиенте | Меняется в `views/layouts/main.php` (`.vh-brand__logo`) |

Если хотите свой растровый логотип:
1. Сохраните в `web/img/logo.png` (300×300 px, прозрачный фон)
2. В `views/layouts/main.php` замените:
   ```html
   <span class="vh-brand__logo"><i class="fa-solid fa-road"></i></span>
   ```
   на:
   ```html
   <img src="<?= Yii::getAlias('@web/img/logo.png') ?>" class="vh-brand__logo" alt="" style="background:none;">
   ```

## 📁 Полная структура папок

```
web/img/
├── about/           ← фото для страницы «О компании»
│   └── hero.svg
├── awards/          ← (опционально) награды компании
├── clients/         ← аватары клиентов в отзывах
│   └── placeholder.svg
├── office/          ← фото офиса (если нужны)
│   └── placeholder.svg
├── partners/        ← логотипы партнёров на главной
│   └── placeholder.svg
├── team/            ← фото сотрудников
│   └── placeholder.svg
├── car-placeholder.svg
└── logo.svg
```

> Загруженные через админку фото авто хранятся в `web/uploads/cars/` — это динамическая папка, её содержимое не трогаем вручную.
